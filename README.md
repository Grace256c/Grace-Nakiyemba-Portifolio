## Overview

This repository contains the source code for my personal software engineering portfolio, built with **React, Vite, JavaScript, and Tailwind CSS** and deployed on **Netlify**.

I'm **Grace Nakiyemba**, a software engineer based in Kampala, Uganda. I build practical backend systems, web applications, AI-enabled solutions, and accessible technology for real-world needs. This portfolio brings together my projects, technical skills, engineering journey, open-source work, and achievements.

**[Visit the live portfolio](https://gracenakiyemba.netlify.app/)**

## Features

- Responsive layout for mobile, tablet, and desktop
- Light and dark theme support
- Animated hero with a constellation background
- Scroll-reveal transitions with reduced-motion consideration
- Responsive navigation and a compact **More** menu
- Engineering journey and categorized technical skills
- Filterable project cards with screenshots, source links, and live demos
- Open-source contributions and emerging technology interests
- Achievements and a downloadable resume
- Working contact form powered by Netlify Forms

## Run Locally

**Prerequisites:** Node.js, npm, and Git.

```bash
git clone https://github.com/Grace256c/Grace-Nakiyemba-Portifolio.git
cd Grace-Nakiyemba-Portifolio
npm install
npm run dev
```

Open the local URL shown by Vite in your terminal.

### Build and Lint

```bash
npm run build
npm run lint
```

The production build is generated in `dist/`.

## Deployment and Contact Form

The site is hosted on [Netlify](https://www.netlify.com/) and connected to this GitHub repository. Its contact form uses **Netlify Forms**. Form delivery works on the deployed website; the local Vite development server does not process Netlify submissions.
